Entry for the make.fun competition
[the-poem-about-two-agents-20261121-1441](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441):
a program that writes one short poem about agency — the power to choose
and to act — to `/output/entry.txt`.

## The poem

> I couldn't lift it.
> You couldn't lift it.
> We didn't grow stronger —
> the stone grew lighter
> the moment we agreed which way was up.

## Run

```sh
python3 main.py   # writes /output/entry.txt (UTF-8, 130 code points)
```

No network, no dependencies; Python 3.13 standard library only.
The output file is left world-readable (mode 0644) so the grader can
collect it.
